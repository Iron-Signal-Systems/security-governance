# ISS Security Control Catalog

This catalog defines the initial organizational controls. A control is not considered fully implemented merely because it appears in this file.

| ID | Control | Owner | Frequency / Trigger | Initial status |
|---|---|---|---|---|
| [ISS-GOV-001](ISS-GOV-001.md) | Security governance review | Governance authority | Annual + material change | Implemented |
| [ISS-RSK-001](ISS-RSK-001.md) | Security risk assessment and register | Security authority | Quarterly + material change | Implemented |
| [ISS-IAM-001](ISS-IAM-001.md) | Account provisioning and removal | System owner | Event-driven | Implemented |
| [ISS-IAM-002](ISS-IAM-002.md) | Privileged-access review | Security authority | Quarterly | Implemented |
| [ISS-ENG-001](ISS-ENG-001.md) | Govern software engineering through ISRAS | Engineering authority | Continuous | Implemented |
| [ISS-VUL-001](ISS-VUL-001.md) | Vulnerability identification and remediation | Security / engineering | Continuous | Implemented |
| [ISS-IR-001](ISS-IR-001.md) | Security incident response | Security authority | Event + annual exercise | Implemented |
| ISS-BCP-001 | Business continuity and recovery | Governance authority | Annual + material change | Defined |
| ISS-SUP-001 | Supplier security review | Governance authority | Before use + periodic review | Defined |
| [ISS-AST-001](ISS-AST-001.md) | Information and system inventory | System owner | Continuous + annual review | Implemented |
| ISS-TRN-001 | Security awareness | Security authority | Onboarding + annual | Defined |
| ISS-EXC-001 | Security exception governance | Security authority | Event-driven | Defined |

## Status meanings

- `Defined`: requirement exists but operating history may not yet exist.
- `Implemented`: the control is operating and required records are being retained.
- `Verified`: the control has completed its required internal review.
- `Externally Assessed`: an independent qualified party has assessed the applicable control boundary.
